# Supply Chain & Delivery Optimization Dashboard

Analyzed 96K+ orders to reduce late deliveries and improve logistics.

## 📊 Live Dashboard
![Dashboard](dashboard.png)

## 🔍 Key Insights from Project
- **On-Time Delivery:** 91.89%
- **Late Deliveries:** 8,000 orders (8.11%)
- **Avg Delivery Time:** 12.56 Days
- **Worst Performing State:** Alabama (23% late)
- **Yearly Trend:** Late deliveries dropped from 20% (2016) to 3% (2018)

## 🛠️ Tech Stack
- Python (Pandas, Matplotlib, Seaborn)
- Jupyter Notebook
- Power BI
- SQL
